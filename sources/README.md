สำนักกฎหมายและวิชาการศาลยุติธรรม (jla.coj.go.th) ฉบับแก้ไขถึงฉบับที่ 25 พ.ศ. 2568

และตัดจุดออก:

    "ปพพ ม.7"      -> ปพพ_ม7.txt
    "ปพพ ม.224/1"  -> ปพพ_ม224-1.txt
    "คร ม.41"      -> คร_ม41.txt
